【培训学时证书系统 · 使用说明】

========================================
一、运行前提
========================================
1. 无需安装任何软件！本包已内置 Node 运行时（bin/node.exe）和全部依赖，
   解压后直接双击 start.bat 即可运行
2. 建议解压到路径不含中文和空格的目录，例如 D:\cert-system

========================================
二、启动系统
========================================
1. 双击 start.bat（或命令行执行 bin\node.exe server.js）
2. 看到服务启动提示后，浏览器打开：
   学员端： http://localhost:3001
   管理端： http://localhost:3001/admin.html （默认密码 admin123）
3. 关闭黑色窗口即停止服务

========================================
三、首次使用流程
========================================
1. 管理端 → 项目配置：核对各培训项目的名称、起止日期、学时（1天=8学时）
2. 管理端 → 数据管理：上传学员 Excel（至少包含：姓名、身份证号、培训项目，
   可选：性别、乡镇、学校、联系电话）
3. 管理端 → 模板配置：上传证书背景图片；点击图片上的文字块，
   可拖拽位置、修改字号/颜色/字体，也可直接改文字内容；点「保存配置」
4. 把学员端地址发给学员，学员输入姓名+身份证号即可下载自己的证书

========================================
四、批量导出证书
========================================
管理端 → 批量导出：按乡镇选择后点「开始导出」，ZIP 内按
「乡镇 / 培训项目 / 每人证书」两级文件夹分类，全部在本机生成，数据不出电脑。

========================================
五、常见问题
========================================
1. 换背景模板、调文字位置：改完刷新页面即可，无需重启服务
2. 改 server.js 等后端代码：需要重启服务才生效
3. 数据都保存在 data/ 目录：
   - students.json  学员数据
   - config.json    配置（项目、字段、密码等）
   - template.jpg   证书背景图
4. 管理密码在管理端「系统设置」中修改
5. 端口被占用：服务默认 3001，若提示端口占用，命令行改用
   set PORT=3001 后重新执行 bin\node.exe server.js（或改其他端口）
6. 换证书背景模板：该功能需要电脑装有 Python 并已安装 Pillow
   （命令 pip install pillow）；其余功能（录入学员、下载证书、
   批量导出、调整文字位置）均无需 Python，解压即用

========================================
六、演示数据（可选）
========================================
本包附带「演示数据.xlsx」（24 条模拟学员），方便你先上传试用整个流程。
系统初始为空白（不含任何学员数据），正式使用前请在管理端
→ 数据管理 上传真实 Excel 即可。
想先体验：数据管理 → 上传「演示数据.xlsx」→ 学员端用其中的
姓名+身份证号即可下载证书；体验完点「清空所有数据」复原为空白。
