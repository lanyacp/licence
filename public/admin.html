培训学时证书管理系统

使用指南

按以下步骤操作，即可让老师下载学时证书

第一步：进入「项目配置」，确认 8 个培训项目的名称、日期、学时与编号规则

第二步：进入「数据管理」，上传包含学员信息的 Excel 表格（需包含：姓名、身份证号、培训项目。其他列可选）

第三步：进入「模板配置」，上传证书背景图片（已根据你提供的 Word 模板生成白底模板），然后在图片上拖拽调整文字字段位置

第四步：保存配置后，将学员端链接 学员端 发给老师们，他们输入姓名和身份证号即可下载证书

发布到公网

配置完成后，点击下方按钮将证书系统发布到公网，生成一个链接发给所有老师

上传学员数据

上传 Excel 表格，系统会自动解析学员信息、按项目生成证书编号和学时。支持 .xlsx 和 .xls 格式
📊

点击或拖拽 Excel 文件到此处上传

必须包含：姓名、身份证号、培训项目。可选：性别、乡镇、学校、学时（学时将被自动计算覆盖）

学员列表

已导入的学员数据，可在搜索框中查找
序号姓名性别身份证号 所属乡镇学校培训项目学时证书编号

培训项目配置

设置 8 个培训项目的名称、培训日期、学时。上传 Excel 后系统会根据这里的配置自动匹配项目、计算学时、生成证书编号

上传证书模板

上传证书背景图片（JPG 或 PNG 格式），建议尺寸宽度 1200-2000 像素
📷

点击或拖拽图片文件到此处上传

支持 JPG / PNG 格式

文字位置配置

在证书图片上拖拽文字到合适位置，右侧可调整字体大小、颜色等属性
操作说明：点击右侧字段列表选中某个字段，然后在左侧图片上拖拽定位。也可直接在图片上点击文字位置进行选中拖拽。修改属性后预览实时更新。

批量导出证书

在本机批量生成学时证书图片，并打包为 ZIP 下载。导出的压缩包内按「乡镇 / 培训项目」两级文件夹分类，例如：
曹里乡 / 义务教育新课标解读培训 / 张三-NLTS4124XP02001.jpg
全部在本机浏览器内完成，学员信息不会上传到任何外部服务器。
